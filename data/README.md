# Dataset Files

- `pilot01_tiny_starter_dataset.csv`: 12-row starter dataset for pipeline debugging.
- `pilot02_expanded_precleaning_dataset.csv`: 120-row expanded pre-cleaning dataset.
- `development_dataset_pilot03_to_pilot06.csv`: cleaned development dataset used during prompt progression.
- `unseen_validation_dataset_pilot07.csv`: final validation dataset used for Pilot_07 and cross-model validation.

Each CSV contains: `id`, `label`, `language`, and `question`.
